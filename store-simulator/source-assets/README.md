# Assets fuente fuera del build web

Esta carpeta conserva originales y copias de trabajo que no necesita descargar
el visitante. Vite copia todo `public/` al build final, por eso los archivos de
respaldo, duplicados y modelos previos viven aqui.

No referenciar estos archivos desde el simulador. Para publicar uno, optimizarlo
primero y copiar solamente el resultado necesario a `public/assets/`.
