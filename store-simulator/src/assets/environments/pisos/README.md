# Esferas por piso

Cada carpeta acepta una sola imagen panoramica 360 en formato JPG, JPEG, PNG,
WebP, HDR o EXR.

Para cambiar una esfera:

1. Borra la imagen anterior de la carpeta del piso.
2. Arrastra la nueva imagen. El nombre puede ser cualquiera.
3. Deja una sola imagen en esa carpeta.
4. Actualiza el navegador con Cmd + Shift + R.
5. Usa T y busca `ESFERA 360` para moverla, rotarla o cambiar su tamano.

Se recomienda 2K (aproximadamente 2048 x 1024) o menos para las pruebas web.
