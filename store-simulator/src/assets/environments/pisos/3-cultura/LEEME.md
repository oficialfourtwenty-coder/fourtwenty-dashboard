Coloca aqui una sola imagen panoramica 360 para el piso CULTURA.

La version final usa `cultura-evening-sky.webp` (2048 x 1024, 50 KB),
derivada de `Evening Sky HDRI 005 B` de ambientCG bajo licencia CC0:
https://ambientcg.com/view?id=EveningSkyHDRI005B

Para reemplazarla, borra la imagen actual y deja una sola imagen `.webp`,
`.jpg`, `.png`, `.hdr` o `.exr` en esta carpeta. WebP 2K es la opcion mas
liviana para el fondo; la iluminacion del piso conserva su HDR compartido.
