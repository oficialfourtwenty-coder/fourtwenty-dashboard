# Terraza PS3 - materiales de prueba

Texturas de 1K convertidas a WebP para que el piso cargue solo cuando se visita
la Terraza. Los originales no forman parte del build.

- `brick-*`: Poly Haven, Brick Wall 005.
- `concrete-*`: Poly Haven, Concrete Floor 01.
- `wood-*`: Poly Haven, Weathered Planks.

Los tres recursos se publican con licencia CC0. Se usan mapas Diffuse, Normal GL
y AO/Rough/Metal. Peso total web aproximado: 1.3 MB.
